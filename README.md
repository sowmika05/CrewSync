# CrewSync
CrewSync is a web-based HR and Employee Management System developed using Django. It helps organizations manage employee information, departments, attendance, leave requests, and other HR-related activities through a centralized platform. 

📌 Project Description

CrewSync is a web-based HR and Employee Management System developed using Django. It helps organizations manage employee information, departments, attendance, leave requests, and other HR-related activities through a centralized platform.

The system provides separate functionalities for administrators and employees, making HR operations more organized, efficient, and easy to manage.

🚀 Features
Employee registration and profile management
Department management
Employee authentication and login
Role-based access for HR/Admin and employees
Attendance management
Leave application and approval
Employee leave history
Password reset and email-based authentication
Dashboard for managing employee-related information
Secure database management using Django ORM
Responsive and user-friendly interface
🛠️ Tech Stack
Backend: Python, Django
Frontend: HTML, CSS, JavaScript
Database: SQLite
Authentication: Django Authentication System
Tools: VS Code, Git, GitHub
🎯 Objective

The main objective of CrewSync is to simplify employee and HR management by providing a centralized system for handling employee records, attendance, leave management, and administrative activities.

💡 Key Benefits
Reduces manual HR-related work
Centralizes employee information
Simplifies leave management
Provides secure authentication
Improves organization and accessibility of employee records
